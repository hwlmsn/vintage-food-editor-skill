# Vintage Food Editor

把普通餐厅随手拍，批量转成具有纯色背景、高级裁切、负空间与复古杂志质感的美食静物照片。

`vintage-food-editor` 是一个面向 Codex / ChatGPT Work 的图像编辑 Skill。它会把用户上传的每张美食照片独立处理为 3:4 竖版成片，尽量保留真实菜品、摆盘、器皿、数量与食欲感，并支持 10 种复古背景配色和用户自有 Logo。

## 功能特性

- 批量处理：一张原图对应一张结果，按上传顺序输出。
- 内容保真：保留菜品种类、食材纹理、酱汁、配菜、器皿和核心摆盘。
- 二次构图：使用偏置构图、局部裁切、物体出框和舒展负空间，避免简单抠图居中。
- 复古质感：模拟中世纪商业静物摄影、旧杂志印刷、胶片颗粒和细微网点。
- 纯色背景：内置 10 种适合美食摄影的克制高饱和配色。
- 批次一致：可让整批照片统一配色，也可逐图指定或自动匹配。
- Logo 叠加：支持用户上传 Logo，成片完成后确定性叠加，不让图像模型重绘品牌图形。
- 质量检查：发现菜品、数量、器皿、摆盘或构图明显偏离时，最多进行一次定向重试。

## Logo 功能

上传品牌 Logo 后，Skill 会先完成美食图片生成和质量检查，再使用确定性脚本将原始 Logo 叠加到成片左上角。

- 默认位置：左上角。
- 默认尺寸：约为画面宽度的 14%，高度最高不超过画面的 12%。
- 默认边距：距离顶部和左侧约为画面宽度的 5%。
- 默认透明度：70%透明，即30%不透明度。
- 保持 Logo 原始比例、颜色、文字和透明通道。
- 推荐上传透明底 PNG 或 WebP。
- 如果 Logo 带有不透明底色，Skill 会先确认保留还是去除，避免误删 Logo 本身的浅色区域。

Logo 不会被写进图像生成提示词，因此可降低文字错误、图形变形和品牌标识被重新设计的风险。

## 安装

将整个 `vintage-food-editor` 文件夹放入 Codex Skills 目录：

```bash
mkdir -p "${CODEX_HOME:-$HOME/.codex}/skills"
cp -R vintage-food-editor "${CODEX_HOME:-$HOME/.codex}/skills/"
```

重新载入 Codex / ChatGPT Work 后，即可通过 `$vintage-food-editor` 调用。

## 使用方法

### 统一配色批量处理

```text
使用 $vintage-food-editor，将我上传的美食照片逐张处理，
统一使用10号孔雀蓝背景，输出3:4。
```

### 逐图指定配色

```text
使用 $vintage-food-editor，四张照片分别使用10、5、2、10号背景。
```

### 自动选择背景

```text
使用 $vintage-food-editor 自动匹配背景颜色，保持整批视觉统一。
```

### 添加品牌 Logo

```text
使用 $vintage-food-editor，背景选择10号。
最后一张图片是品牌Logo，请去掉黑底后放在成片左上角，透明度70%。
```

## 处理规则

1. 识别食物原图、风格参考图和 Logo 的不同角色。
2. 确认或推荐背景配色。
3. 每张食物照片独立调用图像编辑能力，避免串菜和跨图借用器皿。
4. 检查菜品、数量、摆盘、器皿、接触阴影与构图。
5. 如有必要，针对具体问题进行一次定向重试。
6. 成片通过检查后，再叠加用户上传的 Logo。
7. 按原图上传顺序交付最终文件。

## 注意事项

- 图像生成具有一定随机性，无法承诺像素级复刻原图。
- 对数量敏感的菜品，应在请求中明确数量，并检查最终结果。
- 参考图只用于学习构图和视觉风格，不会复制其中的菜品、餐具或文字。
- Logo 合成脚本需要 Python 3 和 Pillow。
- Skill 默认不添加标题、价格、促销文字、边框或额外水印。

## 适用场景

- 餐厅、小酒馆和咖啡店的菜品视觉升级
- 抖音、小红书、公众号和点评平台的美食内容
- 菜单上新、团购活动和品牌社交媒体素材
- 将普通打卡照统一为一组具有品牌感的复古食品摄影
